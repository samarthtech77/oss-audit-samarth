# Open Source Audit - Report Outline

## 1. Origin & Philosophy
- Brief history of Git and its initial creation by Linus Torvalds.
- The driving philosophy behind distributed version control vs centralized systems.
- How Git aligns perfectly with the open source movement's core values.

## 2. License Analysis
- Detailed overview of the GNU General Public License (GPL) v2.0 used by Git.
- What rights this license preserves for end users and developers.
- Comparison with permissive licenses (e.g., MIT, Apache).

## 3. Ethics
- The ethical implications of transparent code and tracking project history.
- How Git fosters global collaboration, transparency, and accountability in teams.
- Addressing the potential for misuse or inclusion of proprietary code in public repositories.

## 4. Linux Footprint
- The heavy reliance of Linux Kernel development on Git.
- Git's massive integration natively into typical Linux distributions.
- Command-line synergies and POSIX compliance advantages.

## 5. Ecosystem
- The huge downstream ecosystem built around Git: GitHub, GitLab, Bitbucket.
- Essential tools and extensions (e.g., Git LFS, Git-flow, CI/CD integrations).
- Standard community contribution pipelines (forks, pull requests).

## 6. Comparison
- Git vs Centralized VCS (e.g., Subversion/SVN, CVS).
- Git vs Other Distributed VCS (e.g., Mercurial).
- Concluding points on why Git emerged as the de-facto standard in the software industry today.
